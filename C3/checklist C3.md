# C 语言第三轮打卡批改清单

默认 4 分；每处小错 -0.5，关键错误 -1；完成好、认真可加 0.5～1，最高 5 分。

## 01A 简答

- [ ] Q1：指针变量存放地址，可通过解引用访问数据。
- [ ] Q2：`&` 取地址；表达式中的 `*` 解引用；声明中的 `*` 表示指针。
- [ ] Q3：`int *a[10]` 是指针数组；`int (*a)[10]` 是数组指针。
- [ ] Q4：函数指针类型正确；知道回调是通过函数指针调用函数。
- [ ] Q5：栈/堆基本区别；`malloc` 在堆；知道全局/静态区、代码区等。
- [ ] Q6：`char *s` 指向字符串常量，不能改；`char s[]` 可改。
- [ ] Q7：指针，指向一个含有 10 个 `int` 的数组。
          函数，参数为 `void`，返回 `int *`。
          函数指针，指向无参数、返回 `int` 的函数。
          数组，5 元素，每个元素都是“无参、返回 `int` 的函数指针”。
          数组，5 元素，每个元素都是“接收一个 `int *` 参数、返回 `int` 的函数指针”。
- [ ] Q8：局部 `static` 保留值；全局变量/函数 `static` 限制在当前源文件。

01A 概念明显错误 -1；只写结论不解释可酌情 -0.5。

- [ ] `mystrcat`：找到 `dst` 末尾，再复制 `src`，包含 `\0`。
- [ ] 测试结果正确：`qweRTY 306_114` 拼接 `514`。

## 04A 动态内存
