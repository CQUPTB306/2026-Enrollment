## 简答 / 改错 / 补全

### A 卷 13（5 分，每点 1 分，最多 5 分）
1. `get_name` 返回局部数组 `buf` 的地址 → 函数返回后 buf 已失效，悬空指针，打印结果是未定义行为。
   改法：改成 `static char buf[16];`，或改由调用者传入缓冲区，或 `malloc`。
2. `malloc(0)`：`n = 0`，分配 0 字节，可能返回 `NULL` 或不可用指针，且**未检查返回值**。
   随后 `p[i] = i`（i 到 4）写越界 → 堆越界写，可能崩溃或破坏堆。
   改法：`n` 用真实需要的 5，且检查 `p == NULL`。
3. `p = realloc(p, ...)` 直接赋值：一旦 realloc 失败返回 `NULL`，原指针丢失 → 内存泄漏且原数据丢失。
   改法：`int *tmp = realloc(p, ...); if (!tmp) { free(p); ... } p = tmp;`
4. 全程没有 `free(p)` → 内存泄漏。
5. 顺序/头文件：`strcpy` 需要 `string.h`（已包含，这点不扣），真正的问题是 1–4 共 4 处；
   答出 4 点即满分，答对顺序与后果各占一部分也可给分。

### 16. `void reverse(char *s)`
```c
void reverse(char *s) {
    if (s == NULL) return;
    char *e = s;
    while (*e != '\0') e++;
    if (e == s) return;
    e--;
    while (s < e) {
        char t = *s; *s = *e; *e = t;
        s++; e--;
    }
}
```
评分：思路（双指针相向）3 分；边界（空串、单字符）1 分；不使用额外数组 1 分；代码完整可编译 1 分。

### 17. `int dedup(int *a, int n)`
```c
int dedup(int *a, int n) {
    if (n <= 1) return n;
    int k = 1;
    for (int i = 1; i < n; i++) {
        if (a[i] != a[k - 1]) {
            a[k++] = a[i];
        }
    }
    return k;
}
```
评分：思路（读写双指针）3 分；边界（n = 0/1）1 分；不使用额外数组 1 分；时间复杂度答对（O(n)）1 分。
